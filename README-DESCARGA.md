# Descarga de Situación · Chiapas para Windows

Esta rama entrega el instalador de la versión inicial 0.1.0 para Windows 10/11 x64. No requiere instalar Node.js ni contratar alojamiento.

1. Descarga `descargas/Situacion-Chiapas-Instalador.zip`.
2. Extrae el ZIP y ejecuta `Situacion-Chiapas-Windows-Instalador.exe`.
3. Abre el acceso Situacion Chiapas y crea tu usuario y contraseña de al menos 12 caracteres.

El instalador no incluye registros personales, bases de datos, contraseñas ni sesiones del entorno de desarrollo. Incluye el catálogo de 65 municipios, especificaciones OSINT y formato de PIN publicados con autorización del propietario.

Esta compilación inicial se construyó y probó funcionalmente en Linux; su ejecución en Windows todavía debe verificarse en el equipo de destino. No tiene firma comercial de editor. No desactives las protecciones de Windows.

La recopilación local requiere equipo/programa encendido e Internet. El complemento remoto gratuito no está desplegado. La revisión completa de fuentes/redes requiere controles adicionales; la descarga automática de estadísticas oficiales continúa pendiente.

Se publica sólo el instalador en esta rama; no se modifica la rama main.
